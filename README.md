# Churn-rate-telephone-contracts

This PowerBi project is built on a dataset representing a telephone company's customer attributes and information, as well as whether or not these customers have let in the past month. 
https://www.kaggle.com/datasets/blastchar/telco-customer-churn
This dashboard is meant to give quick and actionable insights to managers on which segments of customers are leaving, by visualizing the churn rates per attribute. Additionally, the dashboard shows which attributes have the highest churn rates.
